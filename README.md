# 스윗밸런스 자사몰 홈페이지

운동하는 고객을 위한 스윗밸런스(샐러드·건강 간편식 브랜드) 자사몰 홈페이지입니다.
SweetBalance Brand Design System Manual (Ver. 2025.07.25)의
컬러·타이포그래피·컴포넌트·모션 규칙을 그대로 따릅니다.

홈페이지 접속 링크: https://annayu-swb.github.io/sweetbalance_Homepage_annaYU/

## 구성

- `index.html` — 홈페이지 본문 한 파일 (HTML·CSS·JS 포함, 외부 이미지 없음)
  - 첫 화면 — "잘 먹는 것까지가 운동입니다"
  - 대표 제품 — 콥샐러드 중심 구성
  - **운동 루틴 캘린더** — 오늘의 운동과 한 끼를 기록하는 이 페이지의 주인공 기능
  - 브랜드 소개 — 미션·브랜드 성격·슬로건
- `docs/homepage-onepager.html` — 개편 내용을 한 장으로 정리한 설명 자료

## 운동 루틴 캘린더

날짜를 눌러 그날의 운동(근력·유산소·홈트·휴식)과 함께 챙긴 한 끼를 기록하면
도장이 찍히고, 연속 기록·이번 달 누적 단백질·최근 7일 한 끼 단백질 그래프가 갱신됩니다.

기록은 브라우저 `localStorage`에만 저장되며 외부로 전송되지 않습니다.
수정·삭제·전체 초기화를 지원합니다.
